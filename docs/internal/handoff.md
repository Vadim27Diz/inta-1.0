## Факты, нужные для продолжения (сжато — полные в архиве)

- **Tabs**: `Tabs` (набор, Style×Size = 6 вариантов, 3 вложенных Tab-инстанса, первая выбрана,
  техника как у Toggle Group — НЕ Button Group, у того нет Size вовсе) + `Tab` (отдельный набор,
  Style×Size×Selected×State = 48 вариантов). Высоты 32/36/40 (sm/md/lg). Иконка — слот по эталону
  Button, протестирован и подтверждён на одноразовом компоненте (НЕ формальный Figma SLOT-тип — он
  нигде в системе не используется). `TabsContent` в Figma не нужен.
- **Breadcrumb**: Link(3 states) + Page(1) + Separator(1, иконочный слот) + Ellipsis(1, иконочный
  слот) + демо-компонент `Breadcrumb` (1, простой COMPONENT без своих свойств, зашита цепочка
  Link,Separator,Link,Separator,Page) = 7 вариантов всего.
- **Link**: план, не финализирован — `Variant(default/danger)×Size(lg/md/sm)×State(4)` = 24
  варианта, переиспользует цвета Button `variant=link/link-danger`. Нужен явный ОК перед Figma.
- **Chromatic PR #18**: `onlyChanged: true` + `externals: src/styles/**, vite.config.ts` + `skip`
  (только `pull_request`, по заголовку `[skip chromatic]` или метке, пуши в main никогда не
  пропускаются). Branch protection на `main` не настроена (`gh api` → 404).
- **`component.clone()` теряет `componentPropertyReferences`** — подтверждено повторно, фикс нужен
  при каждом клонировании варианта. Эту ловушку всё ещё НЕ занесли в skill — приоритет на начало
  следующей сессии, до первого клонирования для Tabs.
