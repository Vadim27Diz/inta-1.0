## Button — фикс выполнен (2026-10-24)

**Решения человека, применены буквально:**
- `strokesIncludedInLayout=false` на всех **30** вариантах `Variant=outline` с реальной обводкой (15
  `Type=Button` + 15 `Type=Icon Button`), не только на 15 с видимым багом.
- Паддинги по таблице: Button sm/lg вертикаль `0→8` (`spacing/2`, id `5:110`), Button md не трогали
  (уже `8`). Icon Button icon-sm все стороны `0→8` (`spacing/2`), icon/icon-lg все стороны `0→10`
  (`spacing/2-5`, id `5:111`). Горизонтальные паддинги Button (`12/16/24`) не менялись.
- Код (`button.tsx`) не трогал.

**Порядок записи (как согласовано, без отклонений):**
1. **Проверка перед записью** (условие 1): высота текстового слоя `label` живьём для primary/default
   каждого размера — sm `16`, md `20`, lg `24`, иконки `16/16/20` (sm/md/lg) — совпало с расчётом
   таблицы. Запись начата только после совпадения.
2. **Снимок «до»** всех 300 вариантов (id, геометрия, паддинги, привязки переменных,
   `strokesIncludedInLayout`, sizing mode) — `docs/internal/figma-button-size-padding-stroke-before.json`.
3. **Пилот** — по одному варианту (`outline`, `default`) на каждую из 6 пар `Type×Size`
   (`86:44` lg, `86:23` md, `86:2` sm, `536:1513` icon-lg, `86:65` icon, `536:459` icon-sm):
   `strokesIncludedInLayout=false` + паддинг → сверка чисел (все совпали с расчётом, outline Button
   потерял +2px) → скриншоты (6 шт., text/иконка не обрезаны, зазор ровный) — чисто, без стопа.
4. **6 батчей** (оставшиеся 294 варианта, по одной группе `Type×Size` за раз, сверка после каждого):
   Button/lg → md → sm → Icon Button/icon-lg → icon → icon-sm. Каждый батч: единое значение
   width/height на выходе (никаких выбросов), `strokesIncludedInLayout=false` у всех 5 outline в
   группе. Ни одного расхождения ни на одном батче.
5. **Финальная сверка** той же логикой, что `sizeConsistency` в скрипте: **0 нарушений на всех 300**
   (width/height/padding выбросов нет, zeroPadding нет, strokesIncludedInLayout+обводка нет). Плюс
   выборочные скриншоты non-outline вариантов (primary/lg, link/sm, danger/md/disabled, ghost/sm/focus,
   ghost-icon/pressed) — текст/иконка не обрезаны, hover/disabled/focus целы.
6. **`npm run figma:code-diff`** — проверил, добавил `padY: 8` ТОЛЬКО для Button `md` (там `py-2` —
   литеральный CSS padding). sm/lg/icon* намеренно НЕ получили `padY`-пробу: зазор там даёт Fixed-
   высота/квадрат + `items-center`, не CSS padding — `getComputedStyle().paddingTop` читает `0px`
   независимо от Figma, проверка дала бы ложное расхождение. Прогон: **1824 проверки (было 1816, +8
   от нового padY × 4 комбинации), 0 расхождений**.
7. **`figma/layout.json` пересобран целиком** (все разделы, включая `sizeConsistency: []`). Хеш
   `b00e0cc7`, `exporterHash` проставлен через `figma-layout-save.mjs`.
8. **Проверки:** `tsc -b` — чисто. `tokens:check` — 0 ошибок (1 старое предупреждение, не про Button,

## Найдено отдельно, не часть фикса: отдельная инстанс-копия Button вне секций

При пересборке снимка обнаружился 1 инстанс `Button` (id `572:6657`, mainComponent `85:44`
primary/lg/default) лежащий прямо на странице `Components`, не внутри секции — `figma:layout`
правило 1 («только секции на странице верхнего уровня») на нём падает: **1 нарушение**.

**Это не следствие сегодняшнего фикса.** Тот же `572:6657` уже встречался в самом первом read-only
аудите Button этой сессии (до любых правок) — в списке инстансов на странице Components, с
`parentName: "Components"` (не секция), в отличие от остальных 10 с `parentName` вида
`Orientation=horizontal`/`content`/`footer`/`header`. Предсуществующий объект, не трогал (CLAUDE.md:
чужие объекты не удалять/не переписывать без вопроса).

**Решение нужно от человека:** оставить как есть (и формально принять это 1 нарушение
`figma:layout` как известное/не блокирующее), переместить в секцию `Button`, или удалить, если это
случайный мусор. Не чинил сам.

## Открытые решения — доступность (roadmap.md п.4)

   клонирование по `data-slot`), ломает текущую гибкость API.
5. **Slider `aria-labelledby`** — не решено: принимать вместе с `thumbLabel` или взамен.
