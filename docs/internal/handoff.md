## Открытый вопрос — не закрыт, ждёт решения человека

**Kind=seam (вплотную, без зазора) у кольца Input OTP против `outline-offset-2` в коде.**
`src/components/ui/input-otp.tsx` → `InputOTPSlot` красит активный слот control-стилем (зазор 2px,
как у Button), а Figma-кольцо — `Kind=seam` (вплотную, по описанию в `handoff-archive.md`). Два
варианта: привести код к `ring`/вплотную (как Input/Textarea/Select, `Kind=field`) или признать
Input OTP легитимным исключением с зазором. Зафиксировано в `roadmap.md` п.3.
