## 2026-10-25 — Пайплайн Figma→код: три решения по ветке chore/pipeline-tooling

- **`.claude/settings.json` и хук коммитятся в репозиторий**, не остаются личной настройкой —
  решено после явного вопроса, нет возражений про личные разрешения внутри.
- **Ветка не мёржится по частям** — продолжать пакет C (разбить генераторы на блоки,
  дельта-экспорт токенов), слить всё одним заходом в конце, не открывать PR на промежуточный
  результат.
- **`exporterHash` усилен вариантом «б»**: безусловная проверка полноты ключей снимка (не
  только совпадение хеша файла-производителя), а не осталась опциональной через `--hash`.
  Нашла реальную историческую дыру на уже закоммиченном `figma/layout.json` — см. открытый
  вопрос 2 в `pipeline-plan.md`, чинка снимка — отдельное решение, не принято этим же пунктом.

## 2026-10-24 — Button: strokesIncludedInLayout и паддинги по Type×Size

- `strokesIncludedInLayout=false` на всех **30** вариантах `Variant=outline` с реальной обводкой
  (15 `Type=Button` + 15 `Type=Icon Button`), не только на 15 с видимым багом.
- Паддинги: Button sm/lg вертикаль `0→8` (`spacing/2`, id `5:110`), Button md не трогать (уже 8).
  Icon Button icon-sm все стороны `0→8` (`spacing/2`), icon/icon-lg все стороны `0→10`
  (`spacing/2-5`, id `5:111`). Горизонтальные паддинги Button (12/16/24) не менять.
- Код (`button.tsx`) не трогать — фикс только в Figma.
- Порядок записи, которым это сделано (эталон для похожих правок): проверка высоты текста живьём
  → снимок «до» → пилот по одному варианту на каждую из 6 пар `Type×Size` → сверка → 6 батчей
  (по группе за раз, сверка после каждого) → финальная сверка 0/300 → пересборка
  `figma/layout.json`.

## 2026-10-24 — Button: исключение из figma:code-diff для padY

`padY: 8` в проверке добавлен только для Button `md` (там `py-2` — литеральный CSS padding).
`sm`/`lg`/`icon*` намеренно его не получили: зазор там даёт Fixed-высота/квадрат + `items-center`,
не CSS padding — `getComputedStyle().paddingTop` читает `0px` независимо от Figma, проверка дала
бы ложное расхождение.
