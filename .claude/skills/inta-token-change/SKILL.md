# Изменение токена

Файл уже наполнен — любая правка это «добавить/изменить», не «импортировать заново». Загружай
вместе с `/figma-write-protocol` (это частный случай протокола записи).

## Решить уровень и имя

1. Нужен одному компоненту → слой `Component` (`<component>/<name>`). Нужен 3+ компонентам →
   слой `Theme` (`color/<concept>/<variant>`). Не глобализируй преждевременно.
2. Имя по формуле `[object/] category / concept / [variant] / [state]`
   (`design-tokens/references/naming.md`). Проверь, что такого смысла ещё нет под другим именем —
   `token-catalog.md`.
3. **Новый глобальный (Theme) токен или новый бренд — только после согласования с человеком.**

## Запись в Figma (add-only, не полный импорт)

`assets/figma-import.js` с `ONLY=["Theme"]` перезапишет значения/scopes/описания **всем**
переменным коллекции — ревью не отличит это от случайной правки. Вместо этого:

1. Снимок хешей **до**: read-only скрипт по коллекциям (`figma-variables.md` →
   «Добавление токенов в существующий файл» — там же шаблон хеш-функции и канонической строки).
2. Add-only скрипт: создаёт только перечисленные объекты, пропускает существующие по имени (с
   логом), не делает ни одного `setValueForMode`/`renameMode`/`scopes=` по тому, что уже есть.
3. Снимок хешей **после**, исключая новые имена — каждый хеш коллекции обязан совпасть с «до».
   Это доказательство «добавили, ничего не задели»; счётчики его не дают.
4. `assets/figma-export.js` (можно обрезать до `_problems`) — ловит `ALL_SCOPES`, пустой/не
   совпадающий code syntax, непривязанное свойство текстового стиля, hex в Theme.

## После записи

1. Экспорт → `tokens/tokens.json` → `npm run tokens:build` (+ `tokens:catalog`, если состав
   токенов изменился).
2. **Пересобери `Foundations`** (`figma-variables.md` → «Страница Foundations») — её подписи
   статичны, после правки токена они врут, пока страницу не пересобрали.
3. `npm run tokens:contrast` → 0 ошибок для пар `X`/`on-X` во всех состояниях × 4 комбинации.
   Контраст ниже 4.5:1 на `on-*` — стоп, спроси человека, не выбирай цвет сам.
4. `npm run tokens:check` → 0 ошибок (компоненты, которые используют новый токен).
5. Коммит: `tokens: <что поменялось>`. В отчёте — упомяни новый токен явно.

## Ошибка класса «Theme — только алиасы»

`Theme` и `Component` — **только алиасы** на нижний слой. Hex в этих слоях — ошибка, экспорт
покажет в `_problems`; не исправляй значение сам, если дизайн в Figma противоречит правилу —
покажи место и предложи токен, спроси человека.
