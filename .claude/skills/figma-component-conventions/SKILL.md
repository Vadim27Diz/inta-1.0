# Общие правила компонентов в Figma (Inta 1.0)

Figma fileKey uUb84csG4wOfbUjB38ODiz. Перед записью: /figma-use, create_session, пользователь подтвердил «версия сохранена». Частные правила: figma-button-geometry (Button), figma-icon-slots (иконки).

## Порядок значений свойств

- Size всегда от большего к меньшему: lg, md, sm (у иконочных icon-lg, icon, icon-sm). Если у компонента только часть размеров, порядок тот же без пропущенных.
- Порядок виден в выпадающем списке панели Properties и должен совпадать с порядком в сетке набора. Хаотичный порядок (md, sm, lg) считается ошибкой.
- Figma хранит порядок значений по порядку создания значения; перестановка слоёв порядок в списке не меняла (проверено на Button). При создании набора создавать значения сразу в нужном порядке. Исправление существующего порядка: сначала пилот и согласование с пользователем.
- После любого изменения свойств открыть выпадающие списки и проверить порядок глазами.

## Размеры у связанных компонентов

- Компоненты, которые стоят рядом в форме (Button, Input, Textarea, Select, Native Select, Label, Field), имеют один и тот же набор значений Size, один и тот же порядок и согласованные размеры текста и высоты.
- Field собирает Label, поле, подсказку и ошибку. У него те же значения Size, и в каждом варианте лежит Label и контрол того же размера.
- Размер в Figma, которого нет в коде, не добавлять без решения пользователя. Если размер добавляется в Figma, согласовать, что он появится и в коде, документации и историях.

## Правила записи

- Сначала только чтение и план; записи после ответа пользователя и «версия сохранена».
- Снимок «до» (JSON в docs/internal), пилот на одном варианте, пакеты со сверкой после каждого. Любое расхождение: стоп и отчёт. Сопоставлять по имени варианта и слоту, не по ID (узлы пересоздаются).
- После правок пользователя в Figma читать набор живьём; старые снимки считать устаревшими. Скрытые слои читать с `figma.skipInvisibleInstanceChildren = false`.
- Новое свойство набора меняет имена вариантов: пересобрать `figma/layout.json`, обновить `figma:diff`.
- Цвета, отступы и радиусы только через переменные; паддинг 0 не использовать там, где это не фиксированный квадрат без контента.
- Чужие объекты и неизвестные страницы (например Page 4) не удалять и не переписывать без вопроса: зафиксировать и спросить.
- Состояние записывать в handoff (навык inta-handoff). Архивные файлы менять только через Edit, не Write.
